# 🗺️ Peluang Map
**Aplikasi Web Pendampingan UMKM Berbasis AI**

> Dikembangkan oleh **Agung Mulyana**  
> Panoramic Business Park — Ngamprah, Bandung Barat, Jawa Barat, Indonesia  
> Mahasiswa Doktor Ilmu Manajemen — **Universitas Pasundan (Unpas)**

---

## 📌 Tentang Aplikasi

**Peluang Map** adalah aplikasi web berbasis kecerdasan buatan (AI) yang dirancang khusus untuk mendukung pendampingan dan pengembangan UMKM (Usaha Mikro, Kecil, dan Menengah) di Indonesia.

Aplikasi ini merupakan bagian dari ekosistem digital **Panoramic Business Park** — layanan pendampingan UMKM yang mengintegrasikan teknologi AI dengan pendekatan praktis dan terstruktur.

---

## 🎓 Konteks Penelitian

Aplikasi ini juga berfungsi sebagai **instrumen penelitian** dalam:
- 📄 Jurnal ilmiah bidang Manajemen dan UMKM
- 🎓 Disertasi Program Doktor Ilmu Manajemen — Universitas Pasundan (Unpas)

Penelitian berfokus pada strategi optimalisasi peran UMKM dalam meningkatkan skalabilitas bisnis berbasis AI.

---

## ⚙️ Teknologi

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Netlify Functions (Serverless)
- **AI Engine:** Groq API (LLaMA 3.3 70B)
- **Deploy:** Netlify
